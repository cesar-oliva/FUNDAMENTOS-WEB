Tipos de Bordes en CSS (`border-style`)

Aquí puedes ver cómo se comporta cada propiedad de estilo de borde:

solid
Línea sólida (la más común)
dashed
Línea discontinua (guiones)
dotted
Línea de puntos
double
Línea doble
groove
Efecto tallado / 3D hacia dentro
ridge
Efecto 3D hacia fuera (opuesto a groove)
inset
Efecto de box hundida
outset
Efecto de botón sobresaliente
none
Sin borde (invisible)

Notificación importante

Esta tarjeta tiene un borde grueso solo en el lado izquierdo para darle un toque visual moderno y limpio.
